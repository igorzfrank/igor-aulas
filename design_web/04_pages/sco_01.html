1 🎯 O que são Seletores CSS?
🎯
Definição
Seletores são padrões usados para selecionar e direcionar elementos HTML específicos para aplicar estilos. Eles definem "quem" vai receber as regras de estilo que você escreve.
💡
Analogia simples
Se o HTML é um fichário com muitas fichas, o seletor é como um filtro de busca – você pode buscar por nome (tag), por etiqueta colorida (classe), por identificador único (ID), ou pela posição na gaveta (relacionamentos).
📂 Tipos de Seletores Básicos
🏷️
Seletor de Tipo (Tag)
Seleciona todos os elementos de um tipo. Ex: p { } afeta TODOS os parágrafos.
🎨
Seletor de Classe ( . )
O mais versátil. Ex: .destaque { } afeta todos com class="destaque".
🔢
Seletor de ID ( # )
Para elemento único. Ex: #cabecalho { }. Não pode repetir na página.
⭐
Seletor Universal ( * )
Seleciona TODOS os elementos. Ex: * { margin: 0; } é comum para reset.
2 🧪 Seletores na Prática — Exemplos Lado a Lado
🏷️
Seletor de Tipo (Tag)
/* CSS */
p { color: blue; }
h1 { font-size: 32px; }
<!-- HTML -->
<p>Fica azul</p>
<h1>32px</h1>
🎨
Seletor de Classe ( . ) — O mais usado
/* CSS */
.destaque { background: yellow; }
<!-- HTML -->
<p class="destaque">Amarelo</p>
🔢
Seletor de ID ( # ) — Elemento único
/* CSS */
#cabecalho { background: #333; }
<!-- HTML -->
<div id="cabecalho">Único</div>
⭐
Seletor Universal ( * ) — Reset global
/* CSS */
* {
  margin: 0;
  padding: 0;
}
Remove margens e paddings padrão de todos os elementos.
3 🎭 Pseudo-classes e Pseudo-elementos
🎭
Pseudo-classes
Selecionam elementos em estados específicos: mouse sobre, clicado, focado, primeiro filho, ímpar, etc.
✨
Pseudo-elementos
Selecionam partes específicas de um elemento: primeira letra, primeira linha, antes, depois.

4 📐 Propriedades CSS — O que você pode estilizar

O que são Propriedades CSS?
Propriedades CSS são características que você aplica aos elementos. Se os seletores são "quem", as propriedades são "o quê" você vai mudar.

5 📦 BOX MODEL — O Conceito Fundamental do CSS
🎯
O que é o Box Model?
Box Model é o conceito fundamental do CSS que define que todo elemento HTML é uma caixa retangular composta por quatro camadas concêntricas: conteúdo, padding, borda e margin.
DIAGRAMA VISUAL — BOX MODEL
📏 MARGIN
Espaço externo — entre elementos
🖼️ BORDER
Linha visível ao redor
🧽 PADDING
Espaço interno — respirar
📄 CONTEÚDO
width × height
Texto, imagem, etc.
✅ De fora para dentro: Margin → Border → Padding → Conteúdo — toda caixa HTML segue essa estrutura
💡
Analogia — Uma foto emoldurada
Conteúdo = a foto em si
Padding = espaço entre a foto e a moldura
Borda = a moldura da foto
Margin = espaço entre a moldura e a parede
🧮 Como calcular o tamanho total
Largura Total = width + padding-left + padding-right + border-left + border-right
Altura Total = height + padding-top + padding-bottom + border-top + border-bottom

/* Margin NÃO entra no tamanho — é espaço externo */
💡
Prática recomendada: box-sizing: border-box
Por padrão, padding e border aumentam o tamanho. Com box-sizing: border-box, o tamanho definido já inclui padding e border, facilitando o layout.
/* Aplique globalmente no início do CSS */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
