1 📍 Posicionamento CSS — A Propriedade position
🎯
O que é Posicionamento CSS?
Posicionamento CSS define como um elemento é colocado no documento, controlando se ele segue o fluxo normal da página ou se é reposicionado de forma absoluta, fixa ou relativa.
💡
Analogia simples
O fluxo normal é como uma fila de pessoas. A propriedade position permite tirar alguém da fila e colocar em outro lugar: colado no canto, fixo na parede, ou que não se mova quando a tela rolar.
📂 Valores da Propriedade position
📄
static
Padrão. Segue fluxo normal.
📏
relative
Deslocado da posição original.
🎯
absolute
Sai do fluxo. Posicionado pelo ancestral.
📌
fixed
Fixado na viewport. Não rola.
🧲
sticky
Rola até um ponto, depois fixa.
📐 Exemplos práticos
📌 Header fixo no topo
.header {
  position: fixed;
  top: 0;
}
🧲 Menu que gruda ao rolar
.menu {
  position: sticky;
  top: 0;
}
🎯 Modal centralizado
.modal {
  position: fixed;
  top: 50%; left: 50%;
}
💬 Tooltip sobre elemento
.tooltip {
  position: absolute;
  top: -40px;
}
2 🧩 Flexbox — Conceitos Fundamentais
🎯
O que é Flexbox?
Flexbox (Flexible Box Layout) é um modelo de layout CSS que permite distribuir espaço e alinhar elementos de forma eficiente, especialmente quando o tamanho dos itens é dinâmico ou desconhecido.
💡
Analogia simples
Flexbox é como uma faixa elástica segurando vários itens. Você pode dizer se eles ficam em linha ou coluna, como se distribuem (espaçados, juntos), e como se alinham (centro, topo, base).
📦
Flex Container (Pai)
Elemento com display: flex
🧩
Flex Items (Filhos)
Elementos filhos diretos
DIAGRAMA VISUAL — EIXOS DO FLEXBOX
📦 1 📦 2 📦 3
→ Eixo Principal (row) — justify-content
↓ Eixo Cruzado (column) — align-items
✅ justify-content alinha no eixo principal | align-items alinha no eixo cruzado
🧠
Regra de ouro: O Flexbox controla a distribuição no eixo principal com justify-content e no eixo cruzado com align-items. Memorize esta dupla — é usada o tempo todo.
3 📦 Propriedades do Flex Container (Pai)
📦
Container (Pai)
Define como os filhos se organizam. Controla direção, alinhamento, espaçamento e quebra.
🧩
Items (Filhos)
Cada filho pode ter seu próprio comportamento: crescer, encolher, tamanho base e ordem.
1
display: flex + flex-direction
Ativa o Flexbox e define a direção do eixo principal.
→ row (padrão)
1 2 3
Esquerda → Direita
← row-reverse
3 2 1
Direita → Esquerda
↓ column
1 2 3
Cima → Baixo
↑ column-reverse
3 2 1
Baixo → Cima
2
justify-content — Alinha no eixo principal
Controla a distribuição dos itens ao longo da direção principal (horizontal em row, vertical em column).
📍 flex-start — Início
A B C espaço vazio
🎯 center — Centro
espaço A B C espaço
📍 flex-end — Final
espaço vazio A B C
↔️ space-between — Espaço entre itens
A ↔️ B ↔️ C
🔄 space-around — Espaço ao redor
A B C
⚖️ space-evenly — Espaço igual
A B C
3
align-items — Alinha no eixo cruzado
Controla o alinhamento dos itens na direção perpendicular ao eixo principal.
📏 stretch (padrão)
A B C
Estica para preencher altura
⬆️ flex-start — Topo
A B C
Alinha no topo
🎯 center — Centro
A B C
Alinha no centro
⬇️ flex-end — Base
A B C
Alinha na base
4
flex-wrap + gap
Controla a quebra de linha e o espaçamento uniforme entre itens.
🔄 flex-wrap
nowrap — sem quebra (padrão)
wrap — quebra para linha seguinte
wrap-reverse — quebra para cima
📏 gap
Define espaçamento uniforme entre os itens.

gap: 16px;
Espaço igual em linha e coluna

gap: 10px 20px;
10px entre linhas, 20px entre colunas
🎨 Exemplo com wrap + gap
📦 1 📦 2 📦 3 📦 4 📦 5 📦 6
Itens quebram automaticamente com espaçamento uniforme
/* Exemplo completo de Flex Container */
.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 16px;
}
4 🧩 Propriedades dos Flex Items (Filhos)
Propriedades individuais dos itens
🔢 order
Ordem de exibição
📈 flex-grow
Capacidade de crescer
📉 flex-shrink
Capacidade de encolher
📏 flex-basis
Tamanho base inicial
⚡ flex (shorthand)
Combina os 3 acima
🎯 align-self
Sobrescreve alinhamento
/* Itens com tamanhos flexíveis */
.item-padrao { flex: 1; } /* cresce igualmente */
.item-destaque { flex: 2; } /* dobro do espaço */
.item-fixo { flex: 0 0 200px; } /* tamanho fixo */
5 ⚖️ Position vs. Flexbox — Quando usar cada um?
📍 Use Position quando...
✅ Menu fixo no topo
✅ Modal centralizado
✅ Menu que gruda ao rolar
✅ Tooltip sobre elemento
✅ Ajuste fino de posição
🧩 Use Flexbox quando...
✅ Header com logo, menu e avatar
✅ Galeria de produtos responsiva
✅ Formulário com labels e inputs
✅ Cards alinhados em grid
✅ Centralizar conteúdo
🧠 Frases para lembrar
📍 Position:
"Você fica aqui, exatamente neste lugar."
🧩 Flexbox:
"Vocês todos se organizem juntos, de forma harmoniosa."
