1 🧠 Os Três Conceitos Fundamentais
🎯
O que são Mobile-First, Breakpoints e Media Queries?
Estes três conceitos formam a base do design responsivo. Mobile-first é a filosofia de começar pelo menor dispositivo. Breakpoints são os pontos onde o layout muda. Media Queries são o código CSS que aplica essas mudanças.
📱
Mobile-First
Filosofia: começar pelo menor dispositivo e expandir.
📏
Breakpoints
Pontos de quebra onde o layout se adapta.
📋
Media Queries
Código CSS condicional: @media (min-width: 768px).
💡
Analogia — Água no copo
Mobile-first = encher primeiro um copo pequeno e depois despejar em copos maiores.
Breakpoints = marcas no copo onde você muda a forma de servir.
Media Queries = regras que dizem "quando o copo for maior que X, reorganize".
2 📱 MOBILE-FIRST — Comece pelo Menor
🎯
O que é Mobile-First?
Mobile-first é uma abordagem que prioriza a experiência em dispositivos móveis como ponto de partida. O layout é projetado primeiro para telas pequenas e depois progressivamente aprimorado para telas maiores.
📱
Mobile-First (Recomendado)
Estilos base = Mobile
@media (min-width: 768px) { }
@media (min-width: 1024px) { }
✅ Usa min-width — expande do menor para o maior
🖥️
Desktop-First (Legado)
Estilos base = Desktop
@media (max-width: 1023px) { }
@media (max-width: 767px) { }
❌ Usa max-width — comprime do maior para o menor
⭐ Por que Mobile-First?
⚡ Performance
Mais leve e rápido
🎯 Foco no essencial
Prioriza conteúdo
📈 Tráfego mobile
60%+ do tráfego web
🔍 SEO
Google prioriza mobile
🐛 Menos bugs
Escalar é mais fácil
♿ Acessibilidade
Melhor para todos
3 📏 BREAKPOINTS — Os Pontos de Quebra
🎯
O que são Breakpoints?
Breakpoints são larguras de tela específicas onde o layout precisa mudar para se adaptar a diferentes dispositivos. Eles definem os limites entre mobile, tablet e desktop.
DIAGRAMA VISUAL — BREAKPOINTS RECOMENDADOS
📱 Mobile
até 639px
Estilos base
→
📱 Tablet
640px – 1023px
@media 640px
→
💻 Desktop
1024px – 1279px
@media 1024px
→
🖥️ Desktop Grande
1280px+
@media 1280px
✅ Use min-width (Mobile-First) — comece do mobile e vá expandindo com breakpoints estratégicos
❌ Por dispositivo (evitar)
Criar breakpoints para cada iPhone, Galaxy, iPad. Problema: novos dispositivos surgem sempre.
✅ Por conteúdo (recomendado)
Adicione breakpoints quando o layout quebrar, não quando atinge um tamanho específico.
/* Breakpoints estratégicos mais usados */
/* Mobile: estilos base (sem media query) */

@media (min-width: 640px) { /* Tablet retrato */ }
@media (min-width: 768px) { /* Tablet paisagem */ }
@media (min-width: 1024px) { /* Desktop */ }
@media (min-width: 1280px) { /* Desktop grande */ }
4 📋 MEDIA QUERIES — O Código da Responsividade
🎯
O que são Media Queries?
Media Queries são uma funcionalidade do CSS que permite aplicar estilos condicionalmente com base nas características do dispositivo — largura, altura, orientação, resolução e preferências do usuário.
📏 min-width vs. max-width
✅ min-width (Mobile-First)
@media (min-width: 768px) { }
"MAIOR ou IGUAL a 768px"
❌ max-width (Desktop-First)
@media (max-width: 767px) { }
"MENOR que 768px"
🎯 Faixa específica — Apenas entre dois valores
@media (min-width: 768px) and (max-width: 1023px) {
  /* Apenas entre 768px e 1023px (tablet) */
}
⚙️ Condições disponíveis nas Media Queries

Reduzir animações
5 🧪 Exemplo Prático Completo — Mobile-First na Prática
/* ===== MOBILE (BASE) ===== */
.container { padding: 16px; }
.header { flex-direction: column; }
.cards { flex-direction: column; }
.card { width: 100%; }
.sidebar { display: none; }

/* ===== TABLET (640px+) ===== */
@media (min-width: 640px) {
  .container { padding: 24px; }
  .cards { flex-direction: row; flex-wrap: wrap; }
  .card { flex: 1 1 45%; }
}

/* ===== DESKTOP (1024px+) ===== */
@media (min-width: 1024px) {
  .header { flex-direction: row; }
  .card { flex: 1 1 30%; }
  .sidebar { display: block; flex: 0 0 250px; }
}
6 🎨 Media Queries Modernas — Preferências do Usuário
🌓
Tema Claro/Escuro (Dark Mode)
@media (prefers-color-scheme: dark) {
  body { background: #1a1a2e; color: #e0e0e0; }
}
♿
Reduzir Movimento (Acessibilidade)
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}
📱
Orientação da Tela
@media (orientation: landscape) { /* Horizontal */ }
@media (orientation: portrait) { /* Vertical */ }
