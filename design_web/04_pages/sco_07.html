1 🎯 CONTEXTO — Do design à implementação
🧠 O fluxo completo do desenvolvedor
Nesta atividade, você vai percorrer o fluxo completo de um desenvolvedor front-end: primeiro, replicar a interface no Figma para entender a estrutura visual e, em seguida, codificar no VS Code utilizando HTML e CSS. Este processo desenvolve sua capacidade de traduzir design em código funcional.
💡 Habilidades desenvolvidas
Nesta atividade você praticará: observação detalhada (identificar cada elemento da interface), replicação no Figma (uso de formas, textos, cores, alinhamento), codificação HTML (estrutura semântica) e estilização CSS (cores, fontes, espaçamentos e layout).
2 🎨 ETAPA 1 — Replicar a Interface no Figma
📐 Instruções para replicação no Figma
Observe atentamente a imagem de referência abaixo e replique todos os elementos no Figma. Preste atenção em cada detalhe: cores exatas, tamanhos de fonte, espaçamentos entre elementos, alinhamentos e hierarquia visual. O objetivo é criar uma réplica pixel-perfect da interface apresentada.

Abaixo está a imagem da interface que você deve replicar no Figma. Observe cada elemento com atenção antes de começar a reprodução.
⚠️ Atenção: Não pule esta etapa! A replicação no Figma ajuda você a entender a estrutura antes de codificar. Use as ferramentas de medida, grade e alinhamento do Figma para garantir precisão.
3 💻 ETAPA 2 — Codificar no VS Code
⚙️ Instruções para codificação
Após replicar a interface no Figma, é hora de transformar o design em código. Utilizando o VS Code, crie a estrutura HTML e aplique os estilos CSS necessários para reproduzir fielmente a interface. Consulte as tags recomendadas abaixo como guia para construir seu código de forma semântica e organizada.

4 📊 CRITÉRIOS DE AVALIAÇÃO E ENTREGA
✅ O que será avaliado
🎨 Fidelidade no Figma — A réplica está fiel à imagem de referência?
📐 Precisão visual — Cores, fontes e espaçamentos foram respeitados?
🏗️ Estrutura HTML — Uso correto das tags semânticas?
🎯 Estilização CSS — O código CSS reproduz fielmente o design?
📂 Organização — Código limpo, indentado e com comentários?
📤 Entrega — Link do Figma + arquivos HTML/CSS enviados corretamente?
📦 Forma de entrega
🔗 Link do Figma — Compartilhe o link do arquivo com permissão de visualização.

📄 Arquivos HTML/CSS — Envie os arquivos .html e .css criados no VS Code.

📁 Organização — Coloque tudo em uma pasta compactada (.zip) com nome e turma.

📤 Envio — Faça o upload pelo ambiente virtual da disciplina.
🔄 Resumo do fluxo de trabalho
1️⃣ Observe a imagem de referência com atenção.
2️⃣ Replique a interface no Figma (etapa 1).
3️⃣ Codifique a interface no VS Code utilizando as tags recomendadas (etapa 2).
4️⃣ Compare seu código com o design do Figma para garantir fidelidade.
5️⃣ Revise o código, organize as pastas e prepare a entrega.
6️⃣ Envie o link do Figma e os arquivos HTML/CSS conforme as instruções.
💡 Dica final: Antes de enviar, teste seu código em diferentes navegadores para garantir que a interface está consistente. Verifique também se o link do Figma está acessível em uma janela anônima. Bons estudos e mão na massa! 🚀
