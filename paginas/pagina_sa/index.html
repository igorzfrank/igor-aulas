📋 REGRAS DO PROJETO FINAL
🎯 Objetivo do Projeto
O aluno deve replicar uma página do FIGMA deixando-a totalmente funcional, seguindo todos os padrões visuais e de interação definidos no design. O projeto deve ser desenvolvido em HTML, CSS e JavaScript, com foco em fidelidade ao layout, responsividade e boas práticas de código.
1
🚫 Proibido usar IA — O projeto NÃO deve ser feito com uso de Inteligência Artificial para gerar código.
2
🏫 Feito em sala de aula — O desenvolvimento deve ocorrer durante as aulas, com acompanhamento do professor.
3
🔤 Padrão de nomenclatura — Variáveis e funções devem começar com a inicial da dupla.
let soma → let ibSoma;
function somar() → function ibSomar()
4
📱 Responsivo — O projeto deve funcionar perfeitamente em Desktop e Mobile, com layout adaptável.
5
🎭 Personagem sorteado — O personagem do projeto deve ser o que foi sorteado para a dupla.
6
📂 Repositório original — Os repositórios NÃO podem conter projeto semelhante feito por IA para consulta.
7
📵 Sem celular — Não deve ser usado celular em sala durante a atividade.
